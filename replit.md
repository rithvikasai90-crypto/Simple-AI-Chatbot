# Simple AI Chat

A single-conversation AI chatbot. The browser saves the conversation locally; replies are generated by Gemini through Google AI Studio.

## Run & Operate

- `pnpm --filter @workspace/simple-ai-chat run dev` — run the chat app
- `pnpm --filter @workspace/api-server run dev` — run the API server (port 5000)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- Required secret: `GOOGLEAISTUDIO` — Google AI Studio API key, used only by the API server
- Chat messages are not stored in the project database.

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)

## Where things live

- `artifacts/simple-ai-chat/` — chat interface and browser-side conversation storage
- `artifacts/api-server/src/routes/chat.ts` — server-side Gemini chat endpoint
- `lib/api-spec/openapi.yaml` — source of truth for API request and response types

## Architecture decisions

- The Gemini credential stays on the server; the browser calls the shared API endpoint.
- The initial version keeps one conversation in browser local storage rather than adding accounts or database persistence.

## Product

- Users can ask follow-up questions, try starter prompts, retry failed messages, and clear the conversation.
- Conversation history remains on the current device.
